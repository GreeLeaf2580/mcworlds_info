## 饮食喜恶：从夯到拉

### 夯：个人比较喜欢吃甜味的东西🍰

&emsp;&emsp;比如说裕莲茶楼的蛋挞，蛋糕奶茶 _（也称布蕾奶茶）_，茶百道的铁观音奶冻。接着就是酸甜口的，比如松鼠桂鱼、糖醋排骨，本人对酸的耐受度其实还行。虽然我是贵州人，但不太能吃辣，比起麻辣，我更喜欢吃酸辣，比如说冬阴功汤、老干妈那种辣度 _（所以才逃来上海）_。

### NPC：以下食物不太感冒

&emsp;&emsp;**过于油腻的🧈**。比如说肥肉。年夜饭饭桌上的扣肉、红烧肉我都会挑瘦肉吃。油墩子，大学时食堂在卖，问他商贩油墩子是什么，他也不说，买来吃了才知道是一种萝卜丝做的饼，吃过一次以后不想再吃第二次。

&emsp;&emsp;**腌渍类烟熏类🥓**。比如说酸菜雪菜。首先腌渍类可能会有一些致癌风险，其次是味道不太喜欢。火腿培根腊肉腊肠啥的不经常吃。

&emsp;&emsp;**生食肉蛋🥩和生番茄🍅**。比如说刺身、生鸡蛋。口感比较奇怪，而且半生不熟有点担心卫生问题。日料的话我比较喜欢吃焦糖鳗鱼，但是生鸡蛋是不行。**水煮蛋、茶叶蛋、卤蛋🥚**我也吃得比较少，因为蛋黄有点干噎，个人更喜欢吃煎蛋。凉拌蔬菜倒是无所谓，比如拍黄瓜、凉拌折耳根。但除了生番茄 _（也称圣女果）_，味道不好吃，又酸又苦，熟番茄或者番茄酱可以接受。

&emsp;&emsp;**粽子**。平等地讨厌一切粽子。这个厌烦可能是和贵州老家那边习惯吃肥肉粽子有关，吃过以后总觉得好肥好油腻，无论有没有加肥肉都好油腻，而且会使手上黏黏的。粽叶好似粘鼠板（）。暂时还没试过甜粽子，但推测也不好吃。

&emsp;&emsp;**鲜肉月饼🥮、鲜肉汤圆、咸豆花**。在上海呆过一段时间后尝过，实在是不能接受鲜肉月饼、鲜肉汤圆。个人比较喜欢甜月饼，比如豆沙月饼、莲蓉月饼。对于月饼外型，我比较喜欢广式月饼。小时候有商贩叫卖豆花，吃过一次加辣椒的咸豆花，也不是很喜欢，甜豆花非常好评。

&emsp;&emsp;**咖啡及其制品或者生物碱过多的☕**。比起美式、拿铁，我更偏好茶。对茶饮料可以接受，果茶奶茶啥的。有些生物碱太高的还是要避免，比如说霸王茶姬的一些品类，每次喝我都会心悸睡不着，最后只能靠褪黑素和辅酶Q10救命。本身有一些窦性心律不齐，生物碱太多的应该避免。

&emsp;&emsp;**碳酸饮料🥤**。不是很喜欢碳酸饮料那个冒泡的口感，特别是可乐，所以我一般等没气了才喝。


### 拉完了：禁止投喂

&emsp;&emsp;**榴莲及其制品**。不知道是过敏还是什么，一闻到榴莲的气味就会很头晕。所以即使听其他人说，榴莲非常甜很对我胃口，但还是很遗憾不能吃。也许我究其一生也没法知道榴莲到底是什么味道的。

&emsp;&emsp;**含酒精🍺**。首先酒精是世界卫生组织认定的一类致癌物，安全计量是完全不要接触，其次味道又苦，喝完心悸。搞不懂为什么大家饭桌上要手捧一杯一类致癌物，互相劝别人喝一杯杯一类致癌物，还有对应的一类致癌物店。小时候不小心吃过酒心巧克力，睡了一天。
